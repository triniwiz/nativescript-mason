Property reference ​

Every CSS property MasonKit elements understand, in alphabetical order. Shorthands share a row with their longhands. "Inherited" means a value set on a Mason element reaches its Mason descendants, as in CSS; inheritance does not cross into or out of plain NativeScript views (see Mixing with NativeScript views).

Values are summarized; follow the link in the last column for details and examples. Unless a note says otherwise, a property works on iOS, Android and Windows.

Lengths accept a bare number (CSS px), px, dip, dppx (device pixel), pt, em, rem, %, vw, vh, vmin, vmax and calc()/min()/max()/clamp(), unless noted. See Units.

Not supported ​

These have no effect on MasonKit elements today:

  • order
  • outline and its longhands (use a spread box-shadow for focus rings)
  • font-weight: bolder / lighter, font-style: oblique <angle>
  • perspective and 3D rendering (3D transform functions are flattened to 2D, and iOS ignores most of them)
  • display: contents, grid-template and grid shorthands
  • transition
  • url() references to SVG filters, masks and paint servers

Stylesheet features ​

Selectors, classes, @media, @keyframes, var() custom properties, specificity and pseudo-classes come from NativeScript's CSS engine; MasonKit registers its properties into it, so all of the above work in .css and .scss files and in inline style attributes. See How CSS applies.
